# MediWaste Smart - AI-Powered Medical Waste Management

## Smart India Hackathon 2026

### Project Overview
MediWaste Smart is a comprehensive medical waste management platform featuring AI-assisted waste classification, segregation guidance, and pickup management.

### Features
- 🔐 Role-based Authentication (Admin, Staff, Collector)
- 🤖 AI Waste Classification
- 📦 Pickup Request & Management
- 📊 Admin Dashboard with Analytics
- 🔔 Real-time Notifications
- 📱 Fully Responsive Design

### Tech Stack
- **Frontend:** React + Vite + Tailwind CSS
- **Backend:** Node.js + Express
- **Database:** SQLite
- **Charts:** Recharts
- **Authentication:** JWT
